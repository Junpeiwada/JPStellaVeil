アプリアイコンは画像生成 AI で元絵を作り、ImageMagick で macOS のアイコン形式に加工しています。この文書は再生成・差し替えのための手順書です。

## 使ったもの

| 道具 | 用途 |
|---|---|
| **Gemini API**（モデル: `gemini-2.5-flash-image`、通称 Nano Banana） | 元絵の生成（1024x1024、1:1） |
| blog リポジトリの `scripts/generate_image.py` | 生成スクリプトの流用元。アスペクト比を 1:1 に、スタイルプリセット（アメコミ調）を無しに変えた一時スクリプトで実行した |
| blog リポジトリの venv（google-genai + Pillow） | API 呼び出しの実行環境 |
| **ImageMagick**（`magick`） | 角丸マスク・リサイズ・各サイズへの展開 |
| [Tools/AppIcon/build_icon.sh](../Tools/AppIcon/build_icon.sh) | 元絵 → マスター → Assets.xcassets / .icns の一括変換 |

## 採用プロンプト

採用したのは「リアル星景写真風」路線の 1 枚。天の川と山のシルエットの上に、ソフトフィルターで滲む輝星を置いた構図で、アプリの用途（星景写真へのソフトフィルター後がけ）をそのまま絵にしています。加工済みのマスターが [Tools/AppIcon/AppIcon-1024.png](../Tools/AppIcon/AppIcon-1024.png) です（マスク前の生成原画は残していません）。

```
A breathtaking macOS app icon artwork, full-bleed square composition.
A dramatic night sky filled with the Milky Way galaxy,
thousands of tiny stars, faint nebula clouds in deep blue and violet.
One dominant bright star (like Vega) glowing with a large soft
diffusion halo — the signature look of a soft-focus filter in
astrophotography — warm white core with gentle falloff.
Silhouette of a mountain ridge at the bottom edge.
Rich detail, photorealistic astrophotography style,
deep navy and indigo palette, no text, no border, no rounded corners.
```

プロンプトの意図:

- **full-bleed square / no rounded corners** — 角丸は後工程で正確にかけるので、絵は正方形いっぱいに描かせる（それでも角がわずかに黒く丸まって生成されるため、後工程でクロップして除去する）
- **soft diffusion halo** — このアプリの核であるソフトフィルターの滲みを主役の星に持たせる
- **no text** — 生成 AI は文字を入れたがるので明示的に禁止する

検討時は他に「フィルター越しの星」「現行デザインのリッチ化」の 2 路線も各 2 枚生成して比較したうえで、この案を採用しました（候補画像と比較資料は採用決定後に削除済み）。

## 生成の手順

blog リポジトリの venv を使い、`generate_image.py` を次の 3 点だけ変えた一時スクリプトで実行しました。

1. `image_config` の `aspect_ratio` を `"16:9"` から `"1:1"` に変更
2. スタイルプリセット（`COMIC_STYLE`）の付加を削除し、プロンプトをそのまま渡す
3. 出力を PNG で保存

```bash
/path/to/blog/venv/bin/python 一時スクリプト.py
```

同じ路線で作り直す場合も、この 3 点を守れば `generate_image.py` の流用で生成できます。

## アイコン形式への加工と展開

`build_icon.sh` に元絵を渡すとマスターから作り直し、引数なしなら既存マスターから各サイズを再展開します。

```bash
Tools/AppIcon/build_icon.sh path/to/new-image.png # 元絵からマスターを作り直して展開
Tools/AppIcon/build_icon.sh                       # 既存の AppIcon-1024.png から再展開のみ
```

スクリプト内部では次の加工をしています。

1. **クロップ**: 生成画像の端 60px を落とす（生成時に焼き込まれる角の黒みを除去）
2. **リサイズ**: 824x824 へ（Lanczos）
3. **角丸マスク**: 角丸半径 185px のマスクを 4 倍解像度で描いてから縮小してかける（エッジをアンチエイリアスするため）。角は透過になる
4. **配置**: 1024x1024 の透明キャンバス中央に置く（余白 100px。macOS 標準のアイコングリッド）
5. **展開**: 16px〜1024px の各サイズへ書き出し、`Sources/Resources/Assets.xcassets/AppIcon.appiconset/` と `Tools/AppIcon/AppIcon.icns` を再生成
