## 設計方針

写真を大きく見せ、操作は右側に集約する。作例のように天の川、暗い空、強い建物の照明が混在する写真では、星の効果と前景の漏れを等倍で往復確認することが最重要である。

レイヤーの追加・比較・調整を一画面で終え、モーダル画面へ作業を分断しない。

## 画面構成

```text
┌──────────────────────────────────────────────────────────────────┐
│ 開く  書き出す │ マスク表示  グローのみ │ 表示倍率 │ 表示露出     │
├───────────────────────────────────────┬──────────────────────────┤
│                                       │ [ レイヤー ][ 情報 ]      │
│                                       ├──────────────────────────┤
│                                       │ + 追加                    │
│                                       │ [目] 微細グロー           │
│           メインキャンバス             │ [目] 標準グロー           │
│      拡大、移動、原画比較、            │ [目] 広いハロー           │
│      マスクの半透明オーバーレイ        │ ベース画像                │
│                                       ├──────────────────────────┤
│                                       │ 選択レイヤー              │
│                                       │ 合成: Screen              │
│                                       │ 不透明度    42%           │
│                                       │ 強度        1.8           │
│                                       │ 半径        18 px         │
│                                       │ 明るさ応答  0.50          │
│                                       │ 星とみなす大きさ 12 px    │
│                                       │ 明るさ下限  0.004         │
│                                       │ 空マスク                  │
│                                       ├──────────────────────────┤
│                                       │ [       適用       ]      │
├───────────────────────────────────────┴──────────────────────────┤
│ 100%  グローのみ表示  適用しました (0.16 秒)   メタデータ: 検証待ち │
└──────────────────────────────────────────────────────────────────┘
```

写真情報（ビット深度、画素寸法、ICC プロファイル、メタデータ検証状態）は右パネルの `情報` タブで確認する。画像領域を最優先するため独立したサイドバーは設けず、キャンバスとサイドパネルの境界はドラッグで幅を変更できる。

サイドパネルの幅は記憶し、次回起動時も同じ幅で開く。ウィンドウを広げてもサイドパネルの幅は変わらず、増えた分はキャンバスが受け取る。

適用ボタンと処理進捗はタブの外に置き、どちらのタブを開いていても処理状況が見えるようにする。

## ツールバー

| 操作       | UI                             | 挙動                                                 |
| ---------- | ------------------------------ | ---------------------------------------------------- |
| 開く       | フォルダーアイコン             | 16bit TIFF を開く                                    |
| 書き出す   | 書き出しアイコン               | グローと空マスクを適用し、入力と同じ ICC へ戻して保存する（メタデータも検証） |
| 元画像比較 | スペースキー押下中                | 効果なしの原画を表示する                             |
| グローのみ | アイコン付き切替               | 追加されるグロー成分だけを表示する（原画を含めない） |
| マスク表示 | アイコン付き切替               | 選択レイヤーの適用領域を緑の半透明で表示する         |
| 表示倍率   | `Fit`、`100%`、倍率メニュー    | キャンバスの倍率を固定する                           |

## レイヤー

ベース画像は常に最下段でロックする。グローレイヤーは行ごとに、表示アイコン、名前、サムネイル、合成モード、不透明度を表示する。

- `+` は新しいグローレイヤーを追加する。
- 複製は現在のパラメータとマスクを引き継ぐ。
- ドラッグで順序を変更する。
- 行のコンテキストメニューから複製、名称変更、削除を行う。
- 合成モードは `Screen` と `Add` のセグメントコントロールにする。
- 不透明度は 0〜100% のスライダーと数値入力を併設する。

初期プリセットは、`微細グロー`、`標準グロー`、`広いハロー` の3つを用意する。ただし読み込み直後はレイヤーを作らず、ユーザーが追加したときだけ画像処理を開始する。

### プリセット

レイヤー一覧のヘッダー直下にプリセットバーを置く。保存単位はレイヤー1枚ではなく**レイヤー構成全体**なので、選択レイヤーの真上（インスペクタ側）には置かない。

バーには適用中のプリセット名を表示し、値が変わっていれば `● 変更あり` を添える。右端のメニューから次を行う。

| 項目 | 挙動 |
| --- | --- |
| プリセット一覧 | `組み込み` と `マイプリセット` の2節に分けて表示し、選ぶと適用する |
| `"◯◯" を上書き保存` | 適用中のプリセットを現在の構成で更新する。組み込みには使えない |
| `新規プリセットとして保存…` | 名前を付けて保存する。同名があれば置き換える（シート上で事前に警告する） |
| `プリセットを管理…` | 一覧の名称変更、削除、並べ替え、ファイルの書き出しと読み込み |

- 適用は**既存レイヤーの全置き換え**とする。レイヤーが残っているときだけ確認ダイアログを出す。
- **空マスクはプリセットに含めない**。写真ごとに違うため、適用しても現在のマスクをそのまま残す。
- 組み込みの3種は一覧に出すが、編集・削除・上書きはできない。
- レイヤー追加の `+` メニューにもマイプリセットを並べる。こちらは置き換えではなく、現在の構成へ**重ねる**操作になる。

## インスペクタ

インスペクタは選択レイヤーだけを編集する。各数値はスライダー、数値入力、既定値へ戻すボタンを備える。

| セクション | パラメータ   | 初期値 | 意味                             |
| ---------- | ------------ | ------ | -------------------------------- |
| 合成       | 不透明度     | 50%    | レイヤーの可視率                 |
| グロー     | 強度         | 1.5    | にじむ星の数と明るさを増やす     |
| グロー     | 半径         | 20 px  | ハローの広がり。過大だと空が霞む |
| グロー     | 明るさ応答   | 0.50   | 明るい星ほどハローを大きくする    |
| 星の抽出   | 星とみなす大きさ | 12 px | これより小さい構造を星とみなす。0 にすると空全体が光る |
| 星の抽出   | 明るさ下限   | 0.004  | これより暗い星を捨てる。上げると明るい星だけに絞れる |
| 空マスク   | 自動空マスク | オン   | 前景を自動で除外する             |
| 空マスク   | 地平線       | 自動   | 前景との境界を明示する           |
| 空マスク   | 境界ぼかし   | 60 px  | マスクの境界をなじませる         |

半径の横には「広げすぎると星ではなく空が霞む」警告を、値が推奨範囲を超えたときだけ表示する。常時の説明文では作業領域を圧迫しない。

## マスク補正

自動空マスクは初期値であり、正解ではない。マスク表示をオンにするとキャンバス上で空の適用範囲を確認できる。

- `加算` ブラシ: 効果を適用したい空を追加する。
- `除外` ブラシ: 建物、地面、人工照明を除外する。
- ブラシ径と硬さはキャンバス上の小さなポップオーバーで変更する。
- マスク操作中はグロー合成結果を表示し続ける。

この補正はレイヤーごとに独立させる。弱いグローは天の川にも適用し、強いグローは明るい星だけに限定するといった調整が可能になる。

## 比較と書き出し

`元画像比較` はスペースキーを押している間だけ原画を表示し、離すと合成結果へ戻る。`Option` を押しながらのドラッグは、左右比較の境界を移動する。

キャンバスのマウスドラッグはパン（表示位置の移動）に割り当てる。

書き出しシートでは保存先、ファイル名、出力見込みサイズを表示する。形式は第1版では `16-bit TIFF` 固定とし、次を段階表示する。

1. フル解像度レンダリング
2. TIFF 書き出し
3. メタデータコピー
4. 入出力メタデータ比較

成功時は `メタデータ検証済み` と保持したタグ数を表示する。失敗時は出力ファイルを保存せず、失われたタグ名を示して再試行できるようにする。
