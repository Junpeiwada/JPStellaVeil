## 概要

現在のグロー設定は組み込み3種（`微細グロー` / `標準グロー` / `広いハロー`）を起点にスライダーで詰めるだけで、詰めた値を残す手段がない。
写真ごとに作り込んだレイヤー構成をプリセットとして保存し、別の写真へ再適用できるようにする。

- **対象**: レイヤー構成全体（複数レイヤーの合成モード・不透明度・グロー・星の抽出）を1つのプリセットとして保存 / 上書き / 適用する機能と、その管理 UI
- **やらないこと**:
  - 空マスク（自動 ON/OFF・地平線・境界ぼかし）はプリセットに含めない。写真ごとに違うため、適用しても現在のマスクをそのまま維持する
  - 組み込み3種の編集・削除は不可。一覧に混ぜて表示するが読み取り専用
  - ~~プロジェクト保存（`.stellaveil`）とは別機能~~ → 2026-08-25 にプロジェクト保存自体を取りやめたため、写真ごとの編集状態を残す手段は無くなった。保存されるのは本機能のプリセット（写真をまたぐ設定の型）だけである
- **関連**: [実装計画.md](実装計画.md)（アプリ本体の台帳） / [UI.md](UI.md) / [技術仕様.md](技術仕様.md)

## 注意点

- **適用は1回の更新にまとめる**: レイヤーを1枚ずつ差し替えると自動処理が何度も起動する（[AppState.swift:452-489](../Sources/App/AppState.swift#L452-L489)）
- **適用後に選択レイヤーの ID が変わる**: `selectedLayerID` を付け替えないとインスペクタが空になり、ヒストグラムの再計測も走らない
- **`updatedAt` は上書き時のみ更新する**: 適用しただけで更新日が動くと、管理シートの並びが意味を失う
- ~~**`GlowPresetLayer` はフェーズ6（`.stellaveil`）と項目が重なる**~~ → プロジェクト保存を取りやめたので、`GlowPresetLayer` が `GlowLayer` の唯一の永続化形式になった。項目を足すときは `schemaVersion` を上げる
