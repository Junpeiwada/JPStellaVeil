## 概要

16bit RGB TIFF に星空向けのグローを複数レイヤーで非破壊的に加える macOS ネイティブアプリを実装する。
前景の人工光を不用意ににじませないよう空マスクを備え、書き出し時にはメタデータ保持を自動検証して、検証に失敗した出力は破棄する。

- **対象**: 16bit TIFF の入力 → グローレイヤー編集 → 空マスク適用 → メタデータ検証付き 16bit TIFF 出力
- **やらないこと**: RAW 現像 / JPEG 出力 / 汎用レタッチフィルター / 複数画像のスタック合成
- **やらないと決めたこと**（2026-08-25）:
  - **プロジェクト保存（`.stellaveil`）**: 旧フェーズ6。写真ごとの編集状態を保存して再開する需要が実際には無かった。
    写真をまたいで使い回したいのは設定の「型」のほうで、それは[実装計画-プリセット保存.md](実装計画-プリセット保存.md)で満たせている
  - **空マスクの自前生成と手動補正**: 旧 P5-3（地平線指定・境界ぼかし）/ P5-4（手動ブラシ）/ P5-5b（レイヤー別マスク）。
    Photoshop の「空を選択」で実用精度が出ており、修正が要るときも Photoshop 側で直すほうが早い。
    星景写真の空と地上の境界（木立・稜線・電線）はヒューリスティックが最も苦手とする形状で、
    同等をアプリ単体でやるならセグメンテーションモデルの搭載が必要になる
- **関連**: [技術仕様.md](../技術仕様.md)（確定仕様の正本） / [アプリ全体像.md](../アプリ全体像.md) / [UI.md](../UI.md) / [引き継ぎ.md](引き継ぎ.md)（別マシンでの再開手順。アーカイブ済み） / [実装計画-プリセット保存.md](実装計画-プリセット保存.md)（グロー設定のプリセット機能。本計画とは別台帳） / [実装計画-面グロー.md](実装計画-面グロー.md)（天の川を持ち上げる面グローの追加。ペンディング中。本計画とは別台帳）

## 注意点

- **リニア空間を外れない**: 抽出・ぼかし・合成は必ず linearSRGB で行う。ガンマ空間のぼかしが混入すると星のにじみ形状が変わる
- **縮小プレビューを入れない**: 見た目が変わるため。処理が重くなる分はタイル単位の段階表示とキャンセルで受ける（[技術仕様 §4.1](../技術仕様.md#41-プレビューは縮小しない)）
- **テストデータのパスが直書き**: `TIFFColorManagementTests.swift`、`TIFFImageIOServiceTests.swift`、`GlowRealImageTests.swift` にフルパスがある。別マシンでは環境変数から読む形へ変えるとよい
- **キャンセル粒度はタイル単位**: `MTLCommandBuffer` は投入後に停止できない
