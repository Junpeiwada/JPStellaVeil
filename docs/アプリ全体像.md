## 目的

JPStellaVeil は、現像済みの 16bit TIFF に星空用ソフトフィルター効果を加える macOS ネイティブアプリである。星の明るさに応じたグローを複数の編集可能なレイヤーとして重ね、元画像を損なわずに TIFF へ書き出す。

対象は、天の川と建物・地面などの明るい前景が同居する写真である。前景の人工光を不用意ににじませず、空と星へ効果を限定できることを重視する。

## 第1版の範囲

- 16bit RGB TIFF の読み込み、プレビュー、16bit TIFF 書き出し
- 星成分を抽出してグローを生成するレイヤー
- 複数レイヤー、表示・非表示、順序、不透明度、合成モード
- `Screen` と `Add` のリニア空間合成
- 自動空マスク、地平線指定、境界のぼかし、手動マスク補正
- プロジェクトを `.stellaveil` として保存・再編集
- EXIF、XMP、IPTC、MakerNote を保持した出力と自動検証

RAW 現像、JPEG 出力、レタッチ用の汎用フィルター、複数画像のスタック合成は第1版の対象外とする。

## ユーザーの流れ

1. Lightroom 等で現像済みの 16bit TIFF を開く。
2. アプリが低解像度プレビューと入力メタデータの台帳を作る。
3. グローレイヤーを追加し、強度・半径・星抽出・空マスクを調整する。
4. レイヤーを複製し、微細なグローと広いハローを別々に重ねる。
5. 等倍表示と原画比較で、星、天の川、前景境界を確認する。
6. フル解像度でレンダリングし、メタデータ検証済みの 16bit TIFF として書き出す。

## 画像処理の契約

入力 TIFF はガンマを外してリニア RGB に変換し、以後の抽出、ぼかし、合成はすべてリニア空間で行う。表示時と書き出し時だけ、入力に対応するトーン変換を適用する。

各グローレイヤーは次の処理で生成する。

1. 背景減算で天の川や空のかぶりから点像成分を分離する。
2. 閾値によって高 ISO ノイズを抑える。
3. 空マスクで建物、地面、人工照明を除外する。
4. 4 成分のガウシアン PSF を重ね、星のグローを生成する。
5. レイヤー不透明度を反映し、下位レイヤーへ `Screen` または `Add` で合成する。

`Screen` はユーザーが意図した見た目を作る標準モード、`Add` は光の加算として自然な結果を得るためのモードである。いずれもリニア RGB で計算する。

## 技術構成

| 領域          | 採用技術                         | 役割                                             |
| ------------- | -------------------------------- | ------------------------------------------------ |
| アプリ UI     | SwiftUI                          | ウィンドウ、レイヤー一覧、インスペクタ、状態管理 |
| 描画          | MetalKit                         | 高倍率キャンバス、ズーム、表示変換               |
| 演算          | Metal Compute                    | 背景減算、空マスク、PSF 畳み込み、レイヤー合成   |
| TIFF / 色管理 | ImageIO、CoreGraphics、ColorSync | 16bit 読み書き、ICC プロファイル維持             |
| メタデータ    | 同梱 ExifTool                    | EXIF、XMP、IPTC、MakerNote のコピーと比較検証    |
| プロジェクト  | Codable JSON                     | レイヤー設定、マスク、入力ファイルの識別情報     |

プレビューは画像サイズに応じて縮小して GPU で即時更新し、書き出し時だけフル解像度の Metal 演算を実行する。処理中でも最後に確定したプレビューを表示し続ける。

## TIFF とメタデータの不変条件

「EXIF を一切失わない」は、アプリ固有の要件として次のように定義する。

- 入力 TIFF の画素寸法、ビット深度、方向、ICC プロファイルを維持する。
- EXIF、GPS、XMP、IPTC、MakerNote、サムネイルを出力 TIFF へコピーする。
- 出力後、入力と出力のメタデータを ExifTool で比較し、保持対象に欠落または値の変化があれば書き出しを失敗として扱う。
- ファイルサイズ、更新日時、TIFF のストリップ位置・バイト数など、画素を再符号化すると必ず変化する構造タグは比較対象から除外する。写真情報を示すタグは除外しない。

ImageIO のみで書き出すと MakerNote や未知の独自タグを落とす可能性がある。そのため、アプリに署名済み ExifTool を同梱し、書き出した一時 TIFF に対して入力ファイルのメタデータをコピーする。コピー後に ExifTool の JSON 出力を正規化して比較し、成功したファイルだけを指定先へ移動する。

書き出しダイアログには「メタデータ検証済み」の結果と、保持したタグ数を必ず表示する。

## 保存形式

`.stellaveil` は元 TIFF を複製しない軽量な編集プロジェクトである。入力ファイルのパス、ファイルハッシュ、色管理情報、レイヤー順、パラメータ、マスクを保存する。入力画像が差し替えられた場合はハッシュ不一致を表示し、再リンクを要求する。

## 品質基準

- 16bit TIFF を 16bit のまま入出力する。
- 入力の写真メタデータは上記の検証に合格しない限り出力しない。
- グロー処理はリニア空間で行い、ガンマ空間でのぼかしを許可しない。
- パラメータ変更はプレビューで即座に反映し、フル解像度出力と処理内容を一致させる。
- 前景が強く光る写真では、空マスクを確認・補正できる。
