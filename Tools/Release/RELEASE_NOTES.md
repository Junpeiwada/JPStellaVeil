## インストール

DMG を開き、JPStellaVeil を Applications フォルダへドラッグしてください。
Apple の公証（notarization）済みなので、警告なしに起動できます。

## 動作に必要なもの

- macOS 14 以降
- **ExifTool** — メタデータの補完と検証に使います。未導入でも書き出しはできますが、
  メタデータ検証は行われません。`brew install exiftool` で導入できます。
- **Adobe Photoshop** — 「空を選択」による空マスクの生成に使います。
  初回実行時に Photoshop の操作を許可するダイアログが表示されます。
